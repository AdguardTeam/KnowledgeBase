Use this section if you have any questions or suggestions about AdGuard for Windows. Recomendamos consultar las [FAQ](https://adguard.com/support/faq.html) y esta base de conocimientos antes de contactar con el soporte.

Si notas un anuncio perdido, por favor háznoslo saber usando _Reportar bloqueo incorrecto_.

También puedes unirte a nuestras redes sociales para hablar de AdGuard con otros usuarios, o contactarnos en GitHub para sugerir nuevas funciones o reportar errores.

If you reach out to support and our team asks you for logs or technical data from the app, you can export it here. For step-by-step instructions, see [How to collect AdGuard logs](/adguard-for-windows/solving-problems/adguard-logs).
