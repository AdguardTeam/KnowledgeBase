Use this section if you have any questions or suggestions about AdGuard for Windows. Wir empfehlen Ihnen, die [FAQ](https://adguard.com/support/faq.html) und diese Wissensdatenbank zu konsultieren, bevor Sie sich an den Support wenden.

Wenn Sie eine übersehene Werbung bemerken, teilen Sie uns dies bitte über _Fehlerhaftes Sperren melden_ mit.

Unsere sozialen Kanäle bieten Austausch über AdGuard, GitHub dient zur Meldung von Fehlern und Vorschlägen für neue Funktionen.

If you reach out to support and our team asks you for logs or technical data from the app, you can export it here. For step-by-step instructions, see [How to collect AdGuard logs](/adguard-for-windows/solving-problems/adguard-logs).
