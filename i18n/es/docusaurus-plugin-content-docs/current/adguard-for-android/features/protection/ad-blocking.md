:::info

Este artículo trata sobre AdGuard para Android, un bloqueador de anuncios multifuncional que protege tu dispositivo a nivel del sistema. Para ver cómo funciona, [descarga la aplicación AdGuard](https://agrd.io/download-kb-adblock)

:::

![Bloqueo de publicidad \*mobile_border](https://cdn.adtidy.org/content/kb/ad_blocker/android/features/ad-blocking.png)

Se puede acceder al módulo de bloqueo de anuncios tocando la pestaña _Protección_ (segundo icono a la izquierda en la parte inferior de la pantalla) y luego seleccionando _Bloqueo de anuncios_.

La protección básica bloquea eficazmente los anuncios en la mayoría de los sitios web. Para conocer el mecanismo del bloqueo de anuncios, puedes leer un [artículo dedicado](/general/ad-filtering/how-ad-blocking-works).

La _protección básica_ bloquea eficazmente los anuncios en la mayoría de los sitios web. Para personalizar aún más el bloqueo de anuncios, puedes activar el _bloqueo de anuncios específico por idioma_, que contiene reglas de filtrado para sitios web en idiomas específicos.
