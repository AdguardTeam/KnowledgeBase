:::info

本文适用于 Windows 版的 AdGuard，它是一种多功能广告拦截器，可在系统级别保护用户的设备。 To see how it works, [download the AdGuard app](https://agrd.io/download-kb-adblock).

:::

Windows 版 AdGuard 是一款易于使用的可拦截烦人横幅，弹窗，视频广告和跟踪器的工具。 But that’s not all: it helps you save traffic, load web pages faster, and protect your computer from potentially malicious websites. AdGuard 还可以保护用户免受网络钓鱼网站的侵害，并让孩子远离不当内容。
