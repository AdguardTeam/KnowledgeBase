### Sundhedstjek-notifikationer

Afsnittet _Safari-beskyttelse_ indeholder sundhedsnotifikationer, som advarer om opsætningsproblemer, som kan påvirke filtreringen. Hver notifikation beskriver det registrerede problem og foreslår om muligt en løsning.

Notifikationer er opdelt i to kategorier:

- **Kritiske notifikationer**, fremhævet med orange, indikerer problemer, som kan forhindre AdGuard Mini i at fungere korrekt. Disse problemer omfatter manglende baggrundstilladelser, deaktiverede Safari-udvidelser, fejl i Safari-udvidelser og opbrugt Safari-regelkvote.

![Orange advarsel](https://cdn.adtidy.org/content/release_notes/ad_blocker/mini_for_mac/v2.3/extension_en.png)

- **Standardnotifikationer**, fremhævet med grå, angiver mindre kritiske problemer, som kan reducere beskyttelseskvaliteten, såsom forældede filterlister eller deaktiverede funktioner.

![Gray advarsel](https://cdn.adtidy.org/content/release_notes/ad_blocker/mini_for_mac/v2.3/blocking_en.png)
