Use this section if you have any questions or suggestions about AdGuard for Windows. Recomendamos verificar o [FAQ](https://adguard.com/support/faq.html) e esta Base de conhecimento antes de entrar em contato com o suporte.

Se você notar um anúncio que não foi bloqueado, avise-nos usando _Reportar bloqueio incorreto_.

Você também pode participar de nossos canais sociais para discutir o AdGuard com outros usuários, ou entrar em contato conosco no GitHub para sugerir novos recursos ou relatar bugs.

If you reach out to support and our team asks you for logs or technical data from the app, you can export it here. For step-by-step instructions, see [How to collect AdGuard logs](/adguard-for-windows/solving-problems/adguard-logs).
