Use this section if you have any questions or suggestions about AdGuard for Windows. Consigliamo di consultare le _[FAQ](https://adguard.com/support/faq.html)_ e questa nozionistica prima di contattare l'assistenza.

Se noti un'inserzione non bloccata, facci sapere usando _Fai rapporto per bloccaggio scorretto_.

Puoi anche unirti ai nostri canali social per discutere di AdGuard con altri utenti, o contattarci su GitHub per suggerire nuove funzioni o fare rapporto su errori.

If you reach out to support and our team asks you for logs or technical data from the app, you can export it here. For step-by-step instructions, see [How to collect AdGuard logs](/adguard-for-windows/solving-problems/adguard-logs).
