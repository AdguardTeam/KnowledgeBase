Afsnittet _Support_ har nyttige muligheder ifm. spørgsmål eller evt. problemer:

- FAQ

  Svar på mange spørgsmål og problemer kan findes her

- Anmelde fejlagtig blokering

  Fører til siden, hvor fejl eller problemer kan anmeldes detaljeret

- Kontakt supporten

  Kontakt vores supportteam direkte fra appen, hvilket muliggør at vedhæfte logfiler og app-info

  ![Skærmen Kontakt supporten](https://cdn.adtidy.org/content/kb/ad_blocker/mini_mac/contact-support.png)

- Drøft

  Fører til en side indeholdende links til AdGuards sociale medier og GitHub
