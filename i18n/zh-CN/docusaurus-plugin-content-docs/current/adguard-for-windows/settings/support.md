Use this section if you have any questions or suggestions about AdGuard for Windows. 我们建议您在联系技术支持之前，先查阅[常见问题解答](https://adguard.com/support/faq.html)和本知识库。

如果您发现未被拦截的广告，请通过「报告错误拦截」告知我们。

您也可以加入我们的社交频道，与其他用户一起讨论 AdGuard，或者到 GitHub 上向我们提出新功能建议或报告问题。

If you reach out to support and our team asks you for logs or technical data from the app, you can export it here. For step-by-step instructions, see [How to collect AdGuard logs](/adguard-for-windows/solving-problems/adguard-logs).
