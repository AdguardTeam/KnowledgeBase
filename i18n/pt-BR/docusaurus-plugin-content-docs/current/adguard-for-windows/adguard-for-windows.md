:::info

Este artigo aborda o AdGuard para Windows, um bloqueador de anúncios multifuncional que protege seu dispositivo a nível de sistema. To see how it works, [download the AdGuard app](https://agrd.io/download-kb-adblock).

:::

AdGuard para Windows é uma ferramenta fácil de usar que bloqueia banners, pop-ups, anúncios em vídeo e rastreadores irritantes. But that’s not all: it helps you save traffic, load web pages faster, and protect your computer from potentially malicious websites. O AdGuard também protege você contra sites de phishing e mantém seus filhos longe de conteúdo impróprio.
