:::info

Denne artikel omhandler AdGuard til Windows, en multifunktionel adblocker, der beskytter enheden på systemniveau. For at se, hvordan den fungerer, [download AdGuard-appen](https://agrd.io/download-kb-adblock)

:::

AdGuard til Windows er et brugervenligt værktøj, der blokerer irriterende bannere, pop op'ere, videoreklamer og trackere. Det er dog ikke alt: Den bidrager til at reducere trafik, indlæse websider hurtigere og beskytte computeren mod uønskede og potentielt skadelige websteder. AdGuard beskytter også mod phishing-websteder og beskytter børn mod upassende indhold.

![Hovedskærm \*border](https://cdn.adtidy.org/content/kb/ad_blocker/windows/overview/main_screen_en.png)

Når AdGuard til Windows startes, vises appens hovedskærm. Dens mest distinkte detalje er knappen _aktivér/deaktivér beskyttelse_. På denne skærm kan der også overvåges blokerede annoncer, trackere og trusselsstatistikker, se den aktuelle app-version eller opdatere appen. Der er desuden fire faner øverste til højre: _Indstillinger_, _Support_, _Licens_ og _Om_. Hver af disse er værd at omtale separat.
