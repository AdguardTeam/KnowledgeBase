Use this section if you have any questions or suggestions about AdGuard for Windows. Nous vous recommandons de consulter la [FAQ](https://adguard.com/support/faq.html) et cette Base de connaissances avant de contacter l'assistance.

Si vous remarquez une publicité manquée, veuillez nous en informer en utilisant _Signaler un blocage incorrect_.

Vous pouvez également rejoindre nos réseaux sociaux pour discuter d'AdGuard avec d'autres utilisateurs, ou nous contacter sur GitHub pour suggérer de nouvelles fonctionnalités ou signaler des bugs.

If you reach out to support and our team asks you for logs or technical data from the app, you can export it here. For step-by-step instructions, see [How to collect AdGuard logs](/adguard-for-windows/solving-problems/adguard-logs).
